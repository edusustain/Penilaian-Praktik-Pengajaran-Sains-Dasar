# 🧪 Aplikasi Penilaian Praktik Pengajaran Sains Dasar

Aplikasi berbasis web interaktif untuk memfasilitasi proses penilaian praktik pengajaran (*microteaching*) Sains Dasar bagi mahasiswa calon guru. Aplikasi ini dirancang menggunakan pendekatan **360-degree feedback** yang mencakup Penilaian Diri (*Self-Assessment*), Penilaian Teman Sejawat (*Peer-Assessment*), dan Penilaian Dosen (*Lecturer Assessment*).

---

## 🌟 Fitur Utama

- **Navigasi Multi-Sesi:** Mendukung 2 siklus/praktik pengajaran terpisah untuk tiap mahasiswa (Praktik 1 dan Praktik 2).
- **Pengunggahan Bahan Ajar:** Modul terintegrasi untuk mengunggah bahan ajar/media pembelajaran (Format PDF/PPT/Gambar) serta tautan video rekaman pengajaran.
- **Rubrik Penilaian 3 Perspektif:**
  - 👤 **Penilaian Diri (Self-Assessment):** Membantu mahasiswa melakukan refleksi kritis.
  - 👥 **Penilaian Teman Sejawat (Peer-Assessment):** Mendorong evaluasi kolaboratif antarmahasiswa.
  - 👨‍🏫 **Penilaian Dosen:** Evaluasi komprehensif dari dosen pembimbing.
- **Visualisasi & Analisis Data Interaktif:**
  - Grafik Radar (*Chart.js*) untuk membandingkan persepsi skor antar 3 perspektif.
  - Penilaian otomatis lengkap dengan skor total, rata-rata, dan konversi predikat (A, B, C, D, E).
  - Catatan umpan balik konstruktif (*Kelebihan & Area Pengembangan*).
- **Auto-Save Local Storage:** Data input tersimpan secara otomatis di browser sehingga tidak hilang saat halaman disegarkan (*refresh*).
- **Laporan Siap Cetak (Export PDF):** Tampilan khusus yang rapi dan siap dicetak/disimpan sebagai file PDF laporan resmi.
- **Desain Responsif:** Dibuat menggunakan *Tailwind CSS*, nyaman digunakan di laptop, tablet, maupun *smartphone*.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & JavaScript (ES6+):** Logika aplikasi interaktif tanpa ketergantungan framework berat.
- **Tailwind CSS:** *Utility-first CSS framework* untuk antarmuka yang modern dan responsif.
- **Chart.js:** Perpustakaan grafik untuk visualisasi data analisis radar.
- **Lucide Icons:** Ikon antarmuka yang bersih dan intuitif.
